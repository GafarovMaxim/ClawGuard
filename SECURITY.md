# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 2.5.x   | :white_check_mark: |
| < 2.5   | :x:                |

## Reporting a Vulnerability

Security is paramount for ClawGuard, as it serves as a fail-closed kill switch protecting sensitive network traffic and API keys.

If you discover a vulnerability or potential IP leak vector:
1. Please do not open a public issue.
2. Submit your report privately via GitHub Security Advisories on this repository, or contact the maintainer directly.
3. Include details of the network environment, VPN software used, and steps to reproduce.
4. We aim to respond within 48 hours and release patches promptly.
